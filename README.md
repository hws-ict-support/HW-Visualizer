# HW Visualizer

A professional C# Windows Forms application for visualizing hardware data.

## Features
- Hardware monitoring
- Data visualization
- System information display

## Requirements
- .NET Framework 4.7.2 or higher
- Windows 10 or later

## Installation
1. Clone the repository
2. Open the solution in Visual Studio
3. Build the project
4. Run the application
